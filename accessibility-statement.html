01

Commitment to Digital Inclusion & Equity

In Discipline-Based Education Research (DBER) and higher-education andragogy, equity and cognitive access are non-negotiable foundations of meaningful learning. Just as physical and virtual classrooms must be designed under Universal Design for Learning (UDL) principles, our academic web presence must serve all visitors regardless of visual, motor, auditory, or cognitive abilities.

We design, build, and maintain this digital ecosystem in accordance with the principles of the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018 and international best practices established by the World Wide Web Consortium (W3C).

02

How Accessible This Website Is (User Capabilities)

We want as many people as possible to be able to access and benefit from this website. For example, that means that when visiting this website, you should be able to:

Zoom & Reflow up to 400%

Zoom in up to 300%–400% on desktop and mobile browsers without content spilling off the viewport or requiring horizontal scrolling (WCAG 1.4.10 Reflow).

Full Keyboard Operability

Navigate the entire website using only a keyboard (Tab, Shift+Tab, Enter, Spacebar, Escape) with skip-to-content links and high-contrast visible focus rings.

Screen Reader Compatibility

Listen to the website using modern screen readers (including NVDA, JAWS, VoiceOver on iOS/macOS, Narrator, and TalkBack) supported by semantic HTML5 and ARIA landmark roles.

Dynamic Contrast & Sizing

Customize color contrast (High Contrast Dark, High Contrast Light, Color Inversion) and font sizing on the fly via the built-in Accessibility Tools panel.

Dyslexia & Cognitive Reading Aids

Enable Lexend dyslexia-friendly typography, expanded line and letter spacing, and a horizontal Reading Guide / Line Ruler that assists with visual tracking.

Motion Reduction & Large Cursor

Suppress CSS animations and motion transitions for vestibular comfort, and toggle an enlarged, high-visibility mouse cursor.

03

Compliance Status

Substantially Compliant with WCAG 2.2 Level AA

The Web Content Accessibility Guidelines (WCAG) 2.2 defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

This website is partially / substantially compliant with the Web Content Accessibility Guidelines version 2.2 AA standard, due to the third-party exemptions and non-compliances documented in Section 05 below. All core site markup, interactive controls, typography, and visual assets developed for this portfolio strictly adhere to Level AA (and many Level AAA criteria).

04

Built-in Accessibility Tools on This Site

We have engineered dedicated assistive tools directly into the website's interface. Visitors can access these features from any page by clicking the floating "Accessibility" button in the bottom corner, the "A11y" button in the top navigation, or by pressing the keyboard shortcut Alt + A (or Option + A on macOS).

Tool / Feature Function & Implementation Relevant WCAG Criterion
Skip-Navigation Links Allows keyboard and screen-reader users to bypass repetitive header navigation and jump directly to main content, navigation, or footer. WCAG 2.4.1 (Bypass Blocks) — Level A
Text Resizing (100%–150%) Dynamic typography scaling with four distinct presets (Normal 100%, Medium 115%, Large 130%, Extra Large 150%) that reflow cleanly without layout clipping. WCAG 1.4.4 (Resize Text) — Level AA
High Contrast Modes Toggle between Default, High Contrast Dark (Black & Gold), High Contrast Light (Stark Black & White), and Color Inversion with contrast ratios exceeding 7:1. WCAG 1.4.3 (Contrast Minimum) & 1.4.6 (Contrast Enhanced)
Dyslexia-Friendly Font (Lexend) Applies Google Fonts Lexend, an evidence-based typeface engineered in collaboration with educational researchers to reduce visual stress and character confusion. WCAG 1.4.12 (Text Spacing) & UDL Guidelines
Highlight All Links Renders bright high-contrast background badges and distinctive underlines across all interactive hyperlinks, ensuring links do not rely solely on color. WCAG 1.4.1 (Use of Color) — Level A
Enhanced Text & Line Spacing Expands body line-height to 2.0, letter spacing to 0.08em, and word spacing to 0.16em to mitigate cognitive fatigue and crowded text. WCAG 1.4.12 (Text Spacing) — Level AA
Reading Ruler / Focus Bar A horizontal translucent guide line that follows mouse cursor movements and keyboard focus, helping readers with ADHD or dyslexia maintain focus across lines. Cognitive Ergonomics & Assistive Reading
Reduced Motion Suppresses CSS animations, transitions, and smooth scrolling for individuals sensitive to motion sickness or vestibular disorders. WCAG 2.3.3 (Animation from Interactions) — Level AAA
Focus Trapping & Escape Dismiss Accessible dialog management for the Academic CV modal, photo lightbox, and accessibility panel; focus is contained while open and returned upon closing. WCAG 2.1.2 (No Keyboard Trap) — Level A
Preference Persistence Accessibility settings are saved locally to your device via localStorage, maintaining your customizations on subsequent visits. Usability & Persistent User Preferences
05

Non-Accessible Content & Known Limitations

Despite our best efforts to ensure the accessibility of this website, we recognize that some content may not yet be fully accessible. Modeled on institutional transparency standards, we document all known limitations below:

1. External Scientific Journal & Publisher Repositories (Third-Party Platforms)

Description: Several research papers and book chapters authored by Monolina Sarkar link out via Digital Object Identifiers (DOIs) to external academic publisher platforms (e.g., Elsevier ScienceDirect, Springer Nature, Wiley Environmental Microbiology, Taylor & Francis / CRC Press, and Apple Academic Press). These external publisher portals and archived journal PDF downloads are hosted on third-party commercial systems outside our direct editorial control.

WCAG Criteria: Some external publisher PDFs may fail WCAG 1.1.1 (Non-text Content), WCAG 1.3.1 (Info and Relationships), and WCAG 2.4.2 (Page Titled) because they lack full structural tagging or reflow mechanisms.

Accessible Workaround: We provide full plain-text bibliographic citations, abstracts, and contextual research summaries directly on this website. Furthermore, any researcher or student may request an accessible copy (accessible Word document, tagged PDF, or Markdown plain text) by emailing monolinasarkar1@gmail.com.

2. Complex Biochemical Diagrams & Molecular Pathways

Description: Certain biological pathway diagrams (such as Nod-factor independent rhizobial crack-entry symbiosis and heavy-metal stress mechanisms) present multi-scale spatial and molecular relationships that are inherently complex.

WCAG Criteria: WCAG 1.1.1 (Non-text Content). While all diagrams feature descriptive HTML alt text and accompanying text captions, intricate chemical interactions can be challenging to convey completely through short alternative text alone.

Accessible Workaround: Detailed narrative breakdowns of the biochemical hypotheses and empirical findings are provided in the surrounding text and research inquiry tabs. Visitors may also request one-on-one narrative walkthroughs.

3. Outbound Academic Profiles & External Services

Description: External links to academic directories such as ORCID (0000-0002-8172-1111), Web of Science ResearcherID (GRY-0666-2022), and LinkedIn are operated under the respective governance of those platforms.

WCAG Criteria: WCAG 3.2.4 (Consistent Identification). All external links open with clear visual external link indicators (↗) and accessible target="_blank" rel="noopener noreferrer" attributes.

06

Disproportionate Burden Assessment

Under Regulation 12 of the Public Sector Bodies Accessibility Regulations 2018, organizations assess whether fixing specific legacy assets imposes a disproportionate operational or financial burden.

We have assessed that retroactively modifying and re-typesetting historical publisher-owned PDFs originally published between 2016 and 2022 would represent a disproportionate administrative burden. However, in keeping with our commitment to open science, we maintain on-demand alternative format conversion for all historical works without charge.

09

Technical Information & Web Standards

Accessibility of this website relies on the following core web technologies to work in concert with assistive technologies and individual browser configurations:

  • • HTML5: Semantic landmark elements (<header>, <nav>, <main>, <footer>, <section>, <article>) establishing logical document structure.
  • • WAI-ARIA 1.2: Accessible Rich Internet Applications landmark roles, state attributes (aria-expanded, aria-controls, aria-label, aria-modal), and live regions (aria-live="polite").
  • • CSS3: Fluid responsive layout grids, CSS Custom Properties for dynamic high-contrast theming, rem-based typographic scaling, and :focus-visible indicators.
  • • ECMAScript (Vanilla JavaScript): Lightweight, dependency-free client logic ensuring rapid rendering, robust keyboard trapping, and client-side preference persistence without invasive trackers.

How We Tested This Website

This website was evaluated using a rigorous combination of automated testing suites and manual human audits:

Automated Audit Suites

  • Google Chrome Lighthouse: Targeting 100/100 Accessibility Score across desktop and mobile profiles.
  • Axe-core DevTools: Comprehensive scanning for WCAG 2.1 and WCAG 2.2 AA violations.
  • WAVE Accessibility Tool: Validating color contrast ratios, alt text presence, and semantic heading hierarchies.

Manual & Assistive Audits

  • Keyboard Navigation Testing: 100% of interactive controls operated solely via Tab, Shift+Tab, Spacebar, Enter, and Escape.
  • Screen Reader Verification: Manual testing using NVDA on Windows and VoiceOver on macOS/iOS.
  • Zoom & Reflow Testing: Evaluated at 200%, 300%, and 400% magnification to prevent horizontal scrolling and text truncation.
